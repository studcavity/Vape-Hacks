# Display

* [PLS916H SPI frame](pls916h-spi-protocol.md) - The bit-banged SPI frame (upstream says 161 bytes) that drives the PLS916H LED matrix: header, 144 LED bytes, checksum, tail.
* [LED frame layout](led-frame-layout.md) - What each of the 144 LED bytes controls: seven-segment digits, halo ring, icons, outer ring, bar levels and column LEDs.
